
# EVOA News Automation

Sistema automatizado de pesquisa, organização e redação de notícias para a newsletter semanal da EVOA.

## Objetivo

Pesquisar diariamente notícias sobre:
- Inteligência Artificial
- Tecnologia e inovação
- Startups e empreendedorismo
- Negócios e tendências de mercado

## Funcionalidades

- Buscar notícias em fontes confiáveis.
- Identificar notícias relevantes.
- Evitar conteúdos duplicados.
- Armazenar links e referências.
- Produzir textos no padrão EVOA News.
- Gerar um rascunho semanal da newsletter.

## Desenvolvimento

Projeto desenvolvido com auxílio do OpenAI Codex.

Todas as notícias devem ser verificadas e aprovadas antes da publicação.
