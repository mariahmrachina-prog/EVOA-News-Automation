# Instruções para desenvolvimento

- Use Python 3.12+ e execute `python -m unittest discover -s tests -v`.
- Nunca invente notícias ou apresente fixtures fictícias como notícias reais.
- Preserve datas de publicação; não as trate como datas dos acontecimentos.
- Preserve o histórico SQLite e registre falhas de fontes.
- Não envie nem publique conteúdo automaticamente. A revisão editorial é obrigatória.
- Não introduza APIs pagas sem autorização.
- Dados de execução ficam em `data/` e `output/`, fora do controle de versão.
